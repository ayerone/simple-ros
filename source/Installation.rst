Installation
============

simple-ros installs nothing like real ROS 2. There's no system package manager step, no distro archive to unpack, and no separate build toolchain to set up first. It's a normal Python package: create a virtual environment, install it, and you're ready to work through the tutorials.

   :maxdepth: 1

   Installation/Ubuntu-Install-How-To

Which install should you choose?
---------------------------------

Ubuntu is the only platform simple-ros targets right now. If you're on something else, a Python virtual environment still works the same way; the :doc:`Ubuntu how-to <Installation/Ubuntu-Install-How-To>` should translate directly aside from the initial ``apt`` step.
